# Agent Skill Synthesis

## Overview
Assists developers in extracting modular capabilities from monolithic agent codebases and packaging them into clean, portable OpenGAP skills with structured frontmatter and instructions.

## Key Capabilities
- Extraction of discrete tools and prompt instructions into skill packages.
- Formatting compliant YAML frontmatter and documentation.
- Validation against OpenGAP specification requirements.
