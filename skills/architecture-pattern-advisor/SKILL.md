# Architecture Pattern Advisor

## Overview
Provides systematic guidance on selecting between autonomous single-agent loops, leader-worker hierarchies, sequential SOP state machines, and real-time streaming architectures.

## Key Capabilities
- Trade-off analysis covering latency, cost, and orchestration complexity.
- Evaluation of framework fits (CrewAI, LangGraph, AutoGen, AgentScope).
- Guardrail and human-in-the-loop topology recommendations.
